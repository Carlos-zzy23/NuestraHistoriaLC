# 🌷 Nuestra Historia - San Valentín 2026

Este es un proyecto web interactivo diseñado como un regalo digital de San Valentín. Simula un **libro de recuerdos (scrapbook)** con navegación horizontal controlada por teclado y efectos visuales dinámicos.

## 🚀 Vista Previa
La página está diseñada para ser visualizada principalmente en dispositivos móviles en modo horizontal para una experiencia de "cuento" inmersiva.

## 🛠️ Tecnologías Utilizadas
* **HTML5 & CSS3:** Maquetación responsiva con CSS Flexbox y animaciones personalizadas (@keyframes).
* **JavaScript (Vanilla):** Lógica para la navegación entre páginas mediante la tecla `ENTER` y sistema de validación de contraseña.
* **Google Fonts:** Integración de fuentes *Dancing Script* y *Playfair Display* para una estética romántica.

## 📖 Estructura del Proyecto
El libro consta de 7 secciones principales:
1.  **Portada:** Bienvenida interactiva.
2.  **Capítulo 1:** El Comienzo (Nuestros primeros chats).
3.  **Capítulo 2:** El "Sí" (Inicio de la relación).
4.  **Capítulo 3:** Nuestro primer 14 de Febrero.
5.  **Capítulo 4:** Nuestra primera salida lejos.
6.  **Capítulo 5:** Celebración de cumpleaños.
7.  **Capítulo 6 (Final):** Sección bloqueada por trivia que revela una carta especial.

## ✨ Características Especiales
* **Lluvia de Corazones:** Animación automática de partículas.
* **Diseño Scrapbook:** Fotos con estilo Polaroid, pines rojos y notas tipo Post-it esparcidas.
* **Navegación Intuitiva:** Transición suave entre páginas (`translateX`) activada por el usuario.
* **Trivia de Seguridad:** Solo quienes conocen la fecha de aniversario (31/08/2024) pueden leer el mensaje final.
